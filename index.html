Ce este GitHub?

GitHub este cea mai mare platformă din lume bazată pe cloud utilizată pentru stocarea, gestionarea și urmărirea modificărilor aduse codului sursă, folosind sistemul de control al versiunilor Git. În timp ce Git rulează local pe calculatorul tău, GitHub oferă un spațiu centralizat online unde programatorii își pot încărca proiectele, pot colabora cu alți dezvoltători și își pot publica aplicațiile pe internet.

De ce este important GitHub?

GitHub reprezintă pilonul central al dezvoltării software moderne datorită următoarelor motive:

  • Standard global în industrie: Este utilizat de milioane de dezvoltători și de majoritatea companiilor tehnologice majore din lume.
  • Portofoliu și CV interactiv: Profilul public de GitHub demonstrează abilitățile practice ale unui programator mai bine decât un CV tradițional.
  • Ecosistem Open-Source: Oferă acces gratuit la sute de mii de proiecte open-source unde oricine poate contribui și învăța.
  • Siguranța datelor: Salvează codul în cloud, prevenind pierderea accidentală a muncii în cazul defecțiunilor de hardware local.

Cum să descoperim și să folosim GitHub?

Utilizarea și explorarea GitHub se realizează parcurgând câțiva pași simpli:

  1. Creează un cont gratuit: Înregistrează-te pe platforma GitHub.com.
  2. Explorează proiecte populare: Accesează secțiunea github.com/explore pentru a descoperi aplicații în tendințe, tehnologii noi și proiecte open-source.
  3. Creează un Repository (Depozit): Inițializează un spațiu dedicat pentru proiectul tău, unde vei stoca codul, fișierele și documentația.
  4. Conectează-l cu GitBash: Folosește terminalul local pentru a sincroniza versiunile de pe calculatorul tău cu serverul GitHub folosind comanda git push.
  5. Publică site-ul tău: Folosește caracteristica GitHub Pages pentru a găzdui gratuit pagini web statice (HTML/CSS/JS) vizibile public pe internet.

Avantajele Cheie ale Utilizării GitHub

  • Controlul Versiunilor (Version Control): Salvează fiecare etapă a codului, permițând revenirea la o versiune anterioară stabilă în orice moment.
  • Colaborare fără conflicte (Branching): Membrii echipei pot lucra simultan pe ramuri separate fără a afecta codul principal (main).
  • Revizuirea Codului (Pull Requests): Modificările noi sunt analizate, comentate și aprobate de colegi înainte de a fi integrate în proiect.
  • Automatizare (GitHub Actions): Permite testarea, verificarea și lansarea automată a aplicațiilor la fiecare trimitere de cod.
  • Securitate Integrată: Scanează automat proiectul pentru depistarea vulnerabilităților de securitate din librăriile utilizate.

Ghid de Lucru în Terminalul GitBash

Pentru a încărca fișierele în repository-ul local și cel de pe GitHub, folosiți următoarea secvență de comenzi:

Nr. Comandă GitBash Explicație / Rol în Proiect
1 git init Inițializează un repository Git local în dosarul curent al proiectului tău.
2 git add . Adaugă toate fișierele modificate în zona de pregătire (staging area) pentru salvare.
3 git commit -m "Adaugat proiectul studiu de caz complet" Salvează modificările în istoricul local cu un mesaj explicativ.
4 git branch -M main Redenumește ramura implicită de lucru în "main" (standardul GitHub).
5 git remote add origin https://github.com/user/repo.git Conectează folderul tău local cu repository-ul online creat pe contul tău de GitHub.
6 git push -u origin main Încarcă securizat codul pe serverul GitHub. Ulterior, pagina poate fi hostată public.

Cum funcționează Git & GitHub? (Concepte Cheie)

Pentru a înțelege arhitectura din spatele platformei, este important să cunoști termenii fundamentali:

📁

Repository (Depozit)

Dosarul digital al proiectului tău care conține toate fișierele, istoricul modificărilor și fișierele de configurare.

📸

Commit

O „fotografie” instantanee a stării codului la un anumit moment. Fiecare commit salvează cine, când și ce a modificat.

🌿

Branch (Ramură)

O linie paralelă de dezvoltare. Îți permite să lucrezi la opțiuni noi fără a afecta codul stabil din ramura principală (main).

🔀

Pull Request (PR)

Procesul prin care propui ca modificările din ramura ta să fie verificate și îmbinate (merged) în ramura principală.

🍴

Fork

O copie personală a repository-ului altcuiva. Îți permite să experimentezi liber fără a schimba proiectul original.

🐛

Issues & Board

Sistemul de urmărire a sarcinilor, erorilor (bugs) și ideilor noi, organizat adesea sub formă de panouri Kanban.

Cum se lucrează efectiv pe o pagină / proiect web?

Colaborarea modernă pe un proiect web respectă fluxul standard GitHub Flow:

1

Clonarea depozitului local

Descarci proiectul pe calculator folosind comanda git clone URL_REPOSITORY pentru a lucra în editorul tău de cod (ex: VS Code).

2

Crearea unei ramuri noi de lucru

Nu modifici direct pe main. Creezi o ramură dedicată: git checkout -b redesign-header.

3

Modificarea codului și Salvarea (Commit)

Editezi fișierele HTML/CSS/JS, verifici rezultatul în browser, apoi salvezi etapele prin git add . și git commit -m "Mesaj".

4

Trimiterea modificărilor și Deschiderea unui Pull Request

Upei ramura pe server (git push origin redesign-header) și deschizi un Pull Request pe interfața web GitHub.

5

Review, Discuții și Imbinare (Merge)

Colegii adaugă comentarii direct pe liniile de cod, propun optimizări, iar după aprobare se apasă butonul Merge Pull Request.

Instrumente de interacțiune directă pe interfața GitHub

  • GitHub Web Editor (Tasta .): Apăsând tasta punct într-un depozit pe GitHub, se deschide un editor VS Code direct în browser pentru modificări rapide.
  • GitHub Pages: Găzduiește gratuit site-ul tău static, generând un link public direct din depozit.
  • Discussions & Code Reviews: Spațiu de dezbatere unde se pot lăsa reacții cu emoji-uri, sugestii de cod editabile direct și aprobări formale.
